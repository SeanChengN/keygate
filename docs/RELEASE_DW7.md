# Keygate dw.7 许可证复制与关联删除

## 行为与接口

修复管理员详情查看／复制待首次激活库存，保留客户端设备证明、AI 就绪门禁及揭示审计；复制不改变激活时间或导出标记。

删除已撤销且无支付关联的许可证时，后台清理当前绑定及未发布候选吉吉 Key。固定 ID、核对凭据指纹、停用并删除，明确核验不存在后才事务删除本地记录。历史轮换 Key 保留，不自动扫描旧的已删除许可证。

- `DELETE /admin/licenses/{id}`：无远端工作为 204；后台受理为 202，包含同一持久任务状态。
- `GET /admin/licenses/{id}/deletion`：进度及脱敏错误码，完成后仍可核查，保留管理员及产品范围权限。
- 认证、429、未知创建、身份不符及未知删除结果保留记录，需管理员处理后明确重试；普通 AI 同步与支付／生命周期变更受删除屏障保护。

## 迁移与回退

增量迁移 `20261114_license_ai_deletion.up.sql` 增加无许可证外键的任务墓碑、账号手动凭据版本及并发保护。任务不存明文 API Key、许可证或管理令牌。

回退前停止新删除请求并核对在途任务；已完成的远端删除不可通过恢复旧数据库撤销。保留本地加密备份、旧镜像和配置快照，不执行破坏性 down migration，不自动补建已删除 Key。

## 验证

2026-11-12 新建唯一测试 Key 验证 DELETE 返回 HTTP 200、code 0，之后 GET 返回 HTTP 404、code 404、message `api key not found`。测试 Key 已删除，无付费模型调用；通用 404 不属于成功。
