# Keygate dw.5 寄售库存与删除修复

已发布版本 `v0.1.4-dw.5`；Movaura 本地审核候选 `2.7.0-beta.8`。2026-11-12 完成 VPS 升级和专用测试库存实机验收。

## 删除异常证据与修复

只读生产核查确认：管理员报告的许可证已不存在，且同事务 `deleted` 审计保留；两张失败测试方案的许可证和订阅引用均为零，但 AI 配置仍引用方案。日志分别出现许可证 DELETE 500 后再次 404，以及空方案 DELETE 持续 500。

方案删除原来直接删父记录，遗漏 AI 配置外键。现改为方案锁内事务检查所有许可证／订阅，删除 AI 配置再删方案，保留历史批次。许可证锁改为及时 409；提交响应丢失时通过独立连接核对本次唯一审计与记录缺失，确认成功才返回 204，否则提示结果待确认。驱动默认读取超时与 10 秒日志吻合，但没有原始驱动错误，不能宣称已唯一确定现场网络根因。

隔离测试通过包装数据库驱动注入“COMMIT 实际成功、驱动返回错误”，验证同一症状与修复；并检查真实回滚、未撤销／支付关联保护、AI 占锁，以及前端 500 后 404 的读回行为。未自动删除此前测试许可证或方案。

## 库存与客户端

管理员批量生成 1–500 张无邮箱 Movaura 月付／年付库存，首次有效设备证明起算，在同一事务写入设备、订阅、AI 锚点和后台任务。未激活不创建远端 Key。配置参与方案统一调整；历史普通签发保持原行为。

新增显式元数据批次 API，单独的管理员清单 TXT 下载只返回软件许可证，每行一个，UTF-8 无 BOM。持久标记防止重复导出，可重新下载原清单；不标记已售出、不对接寄售平台 API，不自动上传。普通列表、CSV／JSON 和 API Key 权限不扩大。

Movaura 使用 DPAPI 保护待激活状态，不发布缺少凭据的授权；界面每 3 秒继续，最多 90 秒，429／认证／明确失败立即停止，超时可手动继续。新库存推荐 beta8，旧证兼容 beta7。

## 验证

新增 Go 隔离数据库测试覆盖批次幂等与并发、首次激活原子性和非法证明、AI 凭据签发、无邮箱邮件、导出原子性与重复并发保护、跨产品权限和 TXT 字节契约。旧 AI 测试按 CI 顺序运行，测试资源收尾不留下活动任务。前端模拟验证批量创建／导出历史、时间戳秒毫秒转换、窄屏布局、等待超时及 429 停止；不调用付费模型。

Movaura 离线授权回归 44 项通过（包含 DPAPI 待激活重载）。完整恢复演练、长期无人值守和第三方平台实际导入不包含于本轮。
