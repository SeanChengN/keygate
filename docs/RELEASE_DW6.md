# Keygate dw.6 账号与额度修复

## 行为与兼容

- 吉吉账号窗口显示已保存状态、更新时间和毫秒到期时间，令牌不回传。GET 仅解密读取，不请求吉吉或续期。
- 寄售选择器显示所属产品全部方案，不符合条件时禁选并注明原因；可前往方案管理调整。现有方案不自动修改，仍须启用、月付或年付订阅、零宽限期及有效 AI/账号配置。
- 月额度 `0` 为不限总额；正数范围 `0.00000001–1000000` USD。保存及同步保留 Key、消费、有效期和月锚点。周期限额、暂停和撤销仍生效。
- AI、寄售提示随中英文切换；业务错误按稳定代码翻译，未知错误显示通用提示和代码。

## API

账号 GET/PUT 的响应追加可空的 `expires_at`（Unix 秒），保留 `configured/state/updated_at`。绑定及操作记录追加 `last_error_code`，原字段保持兼容。无数据库迁移，不改签名授权或客户端协议。

## 验证

使用隔离 PostgreSQL 和合成吉吉响应验证零额度、历史消费保护、寄售首次激活、元数据脱敏及无续期副作用。另完成 Go、前端类型/lint/构建、界面模拟与发布安全门禁。本地 Go vet、完整单元测试、服务器编译、隔离 AI/库存/幂等/删除集成、前端类型/lint/构建均通过。浏览器模拟 8 项通过（保存状态、失败保留、重开回填、全部方案与原因、资格更新、深色窄屏、零额度/中文错误、英文错误）。govulncheck v1.9.0 使用 Go 1.26.11，报告没有受影响的调用；未调用付费模型。远端发布安全门禁以 Release workflow 结果为准。
